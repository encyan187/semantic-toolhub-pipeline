# Semantic ToolHub Pipeline

## Automating Metadata Extraction and Classification of Semantic Web Software

This repository contains the implementation developed as part of the bachelor thesis "Automating Metadata Extraction and Classification of Semantic Web Software".
It provides an end-to-end pipeline for automated metadata extraction and software classification within the Semantic Tool Hub
initiative.


# How to use: 

Use **main_pipline.py** to run the pipeline via the console. 

You must include the software name with an active GitHub Repo. 

It is also possible to include multiple software names.
